# 08. Layout, tampilan, dan lokasi file pendukung UI

Dokumen ini melengkapi **[07_MENU.md](07_MENU.md)** dengan fokus **kerangka tampilan**, **aset**, dan **konvensi path view** per area halaman.

**Buka cepat Cursor:** tekan `Ctrl+P`, ketik: `docs d08`

---

## Ringkasan stack tampilan

| Lapisan | Teknologi / sumber |
|---------|-------------------|
| Template | **Blade** (`resources/views/**/*.blade.php`) |
| CSS framework | **Bootstrap 5.1.3** dari CDN (layout utama) |
| Ikon | **Font Awesome 6** dari CDN |
| JS interaksi ringan | Vanilla JS di layout (sidebar toggle); banyak halaman menambah skrip lewat `@section('scripts')` |
| Build front-end | Tidak memakai Vite/React untuk modul utama; gaya **server-rendered** |

---

## 1. Layout utama aplikasi (sidebar + konten)

### 1.1 `resources/views/layouts/app.blade.php`

| Peran | Detail |
|-------|--------|
| **Fungsi** | HTML lengkap: `<head>`, sidebar, area user/role, logout, **navbar menu** (collapse per grup), `@yield('content')`, skrip Bootstrap & toggle mobile. |
| **Branding** | Logo: `{{ asset('images/logo.png') }}` - file diharapkan di **`public/images/logo.png`** (folder `images` bisa tidak ikut Git; pastikan ada di server). |
| **Variabel warna** | Warna primer override di `:root` (--bs-primary `#2596be`). |
| **Slot Blade** | **`@yield('title')`**, **`@yield('content')`**, **`@yield('scripts')`**, **`@stack('styles')`**, **`@stack('scripts')`**. |
| **CSRF** | `<meta name="csrf-token" ...>` untuk `fetch`/AJAX dari halaman anak. |

**Hampir semua halaman setelah login** memakai:

```blade
@extends('layouts.app')
```

Ini tercakup di controller dengan `return view('nama.folder.view', ...)` sesuai struktur di bawah `resources/views/`.

---

## 2. Layout mirror `resources/views/absen/layouts/app.blade.php`

| Peran | Detail |
|-------|--------|
| **Isi** | Salinan strukturnya sejajar dengan `layouts/app.blade.php` (menu, gaya, CDN sama). |
| **Pemakaian saat ini** | Pencarian `@extends('absen.layouts.app')` pada view **tidak** muncul; mayoritas file di subfolder `absen/` tetap memakai **`@extends('layouts.app')`**. |
| **Gunanya** | Pemeliharaan salinan untuk deployment/lingkungan yang dahulu membedakan entry point tampilan satpam/absen; ketika mengubah sidebar global, **cek konsistensi kedua file** jika modul absen masih memakai mirror. |

---

## 3. Halaman tanpa sidebar (login)

### `resources/views/auth/login.blade.php`

| Peran | Detail |
|-------|--------|
| **Tidak** `@extends` layout aplikasi; dokumen HTML penuh sendiri. |
| **Aset** | Bootstrap + Font Awesome CDN (sama versi familia dengan layout utama). |
| **Gaya** | Inline `<style>` untuk tampilan kartu login (putih tulang, bayangan). |

---

## 4. Halaman cetak / print (tanpa layout sidebar)

Banyak modul membuka view **terpisah** untuk print (window baru atau route khusus): dokumen HTML lengkap, sering dengan `@media print`.

| Contoh area | Lokasi file (contoh) |
|-------------|----------------------|
| Slip gaji cetak | `resources/views/laporan/slip-gaji/print.blade.php` (+ salinan di `absen/laporan/...` bila ada) |
| Perjalanan dinas | `resources/views/perjalanan-dinas/print.blade.php` |
| Biaya perjalanan dinas | `resources/views/biaya-perjalanan-dinas/print.blade.php` |
| Rekapitulasi absensi / all | `resources/views/.../rekapitulasi/print.blade.php`, `rekapitulasi-all/print.blade.php` (+ duplikat di `absen/`) |
| Izin keluar cetak | `resources/views/.../izin_keluar/print.blade.php`, `print-multiple.blade.php` |

**Ciri:** biasanya **tidak** ada `@extends('layouts.app')`; berdiri sendiri untuk lebar kertas dan menyembunyikan kontrol (`no-print`) saat print.

## 5. Pemetaan folder view ke area menu (konvensi lokasi)

Controller merender view dengan notasi titik, mis. `view('master.karyawan.index')` -> **`resources/views/master/karyawan/index.blade.php`**.

Di bawah ini **panduan folder** (bukan daftar setiap file Blade). Duplikat jalur di **`resources/views/absen/...`** menyalin modul yang sama untuk konteks deploy lama; secara fungsional pola layout sama.

| Grup menu sidebar (lihat 07) | Folder view utama (di bawah `resources/views/`) |
|----------------------------|--------------------------------------------------|
| Dashboard Harian | `dashboard.blade.php` (root views) |
| Dashboard Group / BU / Karyawan | `dashboard/group/`, `dashboard/bu/`, `dashboard/employee/` |
| Master Karyawan | `master/karyawan/` + turunan; List aktif: `master/list-karyawan-aktif/` |
| Master organisasi & referensi | `master/divisi`, `departemen`, `bagian`, `seksi`, `golongan`, `shift`, `jenis_ijin`, `jenis_izin`, `jabatan`, `hari_libur`, `hirarki`, `shift-security`, dll. |
| Browse / edit absensi | `absen/` (jika dipakai controller), `edit-absensi/` |
| Tidak absen / statistik | `tidak-absen/`, juga salinan di `absen/absen/` |
| Shift security | `jadwal-shift-security/`, `browse-absensi-security/`, `master/shift-security/`, `override-jadwal-security/` |
| Izin tidak masuk / izin keluar | `tidak_masuk/` atau `tidak-masuk/`; `izin_keluar/` |
| Instruksi lembur / realisasi | `instruksi-kerja-lembur/`, `lembur/` |
| Perjalanan dinas / BPD | `perjalanan-dinas/`, `biaya-perjalanan-dinas/` |
| Saldo cuti / rekapitulasi cuti | `cuti/saldo/`, `cuti/rekapitulasi/` |
| Tukar hari kerja | `tukar-hari-kerja/` (+ `absen/absen/tukar-hari-kerja/` bila paralel) |
| Hutang piutang | `hutang_piutang/` |
| Proses payroll | `proses/periode-gaji`, `closing`, `closing-thr`, `list-thr`, `update-closing-gaji`, `view-gaji`, `periode-thr`, `gapok` di master |
| Laporan | `laporan/slip-gaji`, `slip-thr`, `rekap-*`, `laporan-thr*`, dll. |
| Settings / tarik data / logs / user | `settings/users|roles|permissions`, `tarik-data-*`, `logs/`, `user-login-activity/`, `list-pengajuan-*-api/` |
| Rekap keterlambatan | `rekap-keterlambatan/` |

Untuk nama **tepat** view yang dirender sebuah route: cari **`return view(`** pada controller bersangkutan atau **`routes/web.php`**.

## 6. Aset statis & `public/`

| Lokasi | Isi yang relevan |
|--------|------------------|
| **`public/index.php`** | Front controller Laravel |
| **`public/.htaccess`** | Rewrite ke `index.php` (Apache) |
| **`public/favicon.ico`** | Favicon browser |
| **`public/images/logo.png`** | Diharap ada untuk sidebar (ikon brand) |
| **`public/template_hutang_piutang.csv`** | Template upload hutang piutang |
| **`public/TEMPLATE_HUTANG_PIUTANG_README.txt`** | Dokumentasi singkat template |

**Umum lain:** favicon/logo sering dikelola manual per environment. Path di Blade memakai **`asset('...')`** agar URL mengikuti `APP_URL`.

**Tidak** ada bundle CSS/JS custom terpusat di `public/` untuk modul utama (kebanyakan CDN).

## 7. Kontribusi halaman anak pada layout

| Mekanisme | Kegunaan |
|-----------|----------|
| `@section('title', '...')` | Judul tab browser (dibaca layout jika digunakan). |
| `@section('content')` … `@endsection` | Isi utama halaman di kolom konten. |
| `@push('styles')` | Menambahkan CSS/page-specific `<link>` atau `<style>` **sebelum** `</head>` (layout memuat `@stack('styles')`). |
| `@push('scripts')` | Skrip tambahan yang di-include **setelah** Bootstrap (layout ada `@stack('scripts')`). |
| `@section('scripts')` | Alternatif yield untuk skrip footer (layout juga ada `@yield('scripts')`). |

Gunakan salah satu pola skrip secara konsisten per halaman agar tidak dobel-load.

---

## 8. Rujukan bagi pengembangan UI baru

1. Buat Blade baru di **`resources/views/{modul}/...`**.
2. Tambahkan **`@extends('layouts.app')`** untuk halaman standard ber-sidebar.
3. Daftarkan route + permission di **`routes/web.php`**.
4. Tambahkan link menu di **`layouts/app.blade.php`** (dan sesuaikan **`absen/layouts/app.blade.php`** jika tim masih menyamakan dua jalur).
5. Untuk **cetakan**, pertimbangkan view terpisah tanpa `@extends` agar tidak ikut sidebar.
6. Ikon Bootstrap/FA: sama dengan yang sudah di-load layout; hindari memuat ulang CDN berat pada setiap halaman kecuali perlu library ekstra.
